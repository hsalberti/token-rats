## Measurement

| Metric | Evidence / denominator |
| --- | --- |
| Sent | Resend accepted the message; percentage of recipients |
| Delivered | Signed provider delivery event; percentage of sent |
| Open signals | First tracking-image load or signed provider open event per recipient; percentage of sent |
| CTA clicks | First request to the recipient's opaque redirect link; percentage of sent |
| Returned | Signed-in browser visits after send, within 30 days; percentage of sent |
| Returned after click | Signed-in visit after a CTA click, including people who also visited before clicking |
| New usage trackers | Device sync or heartbeat, with no device/session history at snapshot; percentage of sent recipients without a usage tracker |
| New setup trackers | Enabled automatic capture, with no watcher at snapshot; percentage of sent recipients without a setup tracker |
| After-click activations | First confirmed tracker activity occurred after the first CTA click |
| Existing usage active | Already had tracker history at snapshot; activity after send is not a new installation |

An npm download, copied command, or email click is not counted as installation. Successful authenticated tracker contact confirms activation; offline installs cannot be observed. Email image blocking and privacy preloading distort open signals, and link scanners can create clicks. These counts describe timing, not causal impact. Setup and usage trackers are independent conversions.
